# Clínica Corpo Terra

Site de agendamento e sistema de gestão da clínica (Fase 1 = Clínica, Fase 2 = Loja).

| Pasta / arquivo | O que é |
|---|---|
| `index.html`, `agendar.html`, `confirmacao.html`, `app.js`, `api.js`, `config.js`, `styles.css` | Site público e agendamento online (ficam na raiz porque o endereço do site é a raiz) |
| `assets/`, `img/` | Logos e imagens |
| `sistema/` | Protótipo do sistema com login (profissional e paciente) |
| `mockups/` | Telas de demonstração usadas na apresentação |
| `documentos/` | Documentos para o cliente: Fase 1, Fase 2, apresentação do sistema e levantamento |
| `interno/` | Material interno: PRD, design, levantamento em texto, plano do site, logo e `analise/` do sistema |
| `outros-projetos/` | Dashboard do Lançamento Semente (Método Raízes), não faz parte da clínica |
| `arquivo/` | Versões antigas guardadas (protótipo antigo do prontuário) |
| `ferramentas/prumo/` | Pacote do time de agentes PRUMO (zip, leia-me e créditos). As pastas `.claude` e `.prumo-core` ficam na raiz |

`.env` guarda chaves e não vai para o git.
